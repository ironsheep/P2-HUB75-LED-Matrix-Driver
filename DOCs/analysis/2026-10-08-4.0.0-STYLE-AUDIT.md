# 4.0.0 full style audit (2026-10-08)

Read-only audit of **every tracked `.spin2` file** (35: the 14 driver objects, the demos and their
objects, `isp_hub75_anlyCheck`, `isp_dummy_flash`, `isp_hub75_instrument` and the five test top
files) against every rule of `central:spin2-authoring-guide` that `tools/check_style.py` does not
check (its T1 checks pass). Seven auditors, one per file group (G1-G7 below), each reading every
line. T3 sites are listed, not judged. Line numbers are at `30358d9`.

Stephen (2026-10-08): *"we need style audit done on all .spin2 code before release"*.

**Totals:** 6 MUST-FIX, 98 SHOULD-FIX, 190 NIT.

## Disposition (Stephen, 2026-10-08)

- Every finding is fixed before release, as for the 2026-10-06 audit ("nothing found outstanding").
- **Q1, rule 5.4, answer A:** every PUB that performs an operation and returned TRUE/FALSE returns
  `SUCCESS` or a negative error code: `display.showFrameSet`, `bmp.placeBMP`,
  `bmp.fillScreenFromBMP`, `panel.showFrameSet`, `screenUtils.copyGlyphBlock` / `copyGlyphRows`,
  `instrument.start` / `sampleSecond` / `startTakeCheck`. *"This is public code. It has to be the
  best possible example of how to write code for the P2, which is why we have this style guide."*
- **Q2, rule 2.4:** first answered A (remove the constant-forwarding block in
  `isp_hub75_hwBufferAccess.spin2`), then **superseded** once the history showed why forwarding exists:
  *"forwarding has to be allowed and used only where appropriate."* The interface object that provides
  a method forwards the values that method takes or returns, by reference (`display.HUB75_ADAPTER_1`,
  `hub75Bffrs.DEPTH_*`, `bmp.ROT_*`, each object's status codes); values are defined once, with bases
  allocated on purpose. Criteria and the proposed guide rules 2.4.1 and 4.7.1:
  `DOCs/analysis/2026-10-08-SPIN2-GUIDE-RECOMMENDATION.md`.
- A related finding, the forwarding block in `display` (`TEXT_FONT_*`, `DIR_*`, `SCROLL_*`, `FACE_*`),
  is kept under the same criteria.
- Copyright year in headers and footers: 2024, LICENSE's year (precedent M12).
- T3 sites (rule 5.8, the dedicated-cog pattern) are the driver's established architecture and are
  listed in each group for the record; no change proposed.
